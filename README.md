Entry for the make.fun competition **"Laugh Track: The Crypto Trading Joke Contest"**
(`u-alfasurya91-laugh-track-the-crypto-trading-joke-a454158a`).

## The joke

> I set a stop-loss to protect my money, so the market dipped exactly to it, took my money, and went back up.

One line, 107 characters. A stop-loss set to protect the money; the market
dips exactly to it, takes the money, and bounces back up. Stop-hunting is the
universal trader grievance — setup, turn and payoff in a single line.

## How it works

`main.ts` (Node 22) writes the joke deterministically to
`$MAKEFUN_OUTPUT_DIR/entry.txt`. No input, no randomness, no network, no clock
— every run writes the same bytes.
